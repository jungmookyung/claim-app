# 보험금 청구서 자동작성 (폰 앱 · 홈페이지)

고객 정보를 한 번 입력하면 보험사 청구서가 채워지고, 고객이 동의·서명한 뒤 모바일팩스로 보내는 설계사용 도구입니다. 정무경보험대리점.

주소: https://jungmookyung.github.io/claim-app/ (폰에서 열고 [앱 설치]하면 아이콘 "보험금청구")

- 공식 양식: 삼성화재·메리츠화재·KB손해보험·DB손해보험·삼성생명 청구서·동의서에 그대로 기재 (`forms/`). 그 외 보험사는 표준 양식
- 동의 항목: `forms/consents.js` — 공식 양식 보험사 여러 곳을 골라도 고객에게는 한 번만 묻고 양식마다 옮겨 찍음
- 배상책임: 손해보험사별 "(배상책임)"을 고르면 피해자·피해 내용이 들어간 배상책임 청구서
- 입력 보강: 미성년자(법정대리인 서명), 사고 시각, 진료 구분(통원·입원), 은행 목록, 보험료 자동이체 계좌로 받기
- 고객 서명: 이 폰에서 바로, 또는 카톡 링크로 원격 서명(`sign/`) — 서버 없이 링크 주소 안에만 담아 주고받음
- 팩스: 보험사마다 팩스용 PDF → 모바일팩스 앱 열기(번호 자동 복사). [전체 팩스 준비]는 보험사별로 따로 만듦
- 보험사 청구 팩스번호 안내(`data/fax-directory.js`): 공식 안내로 확인된 번호만 기본값
- 첨부 사진: 서류 모서리 찾아 반듯하게 펴고 흑백 선명하게 (`js/docfix.js`, 폰 안에서 처리)
- 고객 인적사항·계좌는 [고객 저장] 시 폰에만 PIN(6자리)으로 암호화 저장. 서버로 보내는 데이터 없음
- 오프라인에서도 열림 (PWA)

라이선스: 앱 코드 사용은 소유자 전용. `vendor/`의 pdf-lib, html2canvas는 MIT 라이선스 (`vendor/LICENSES.txt`).
