# 보험금 청구서 자동작성 (폰 앱)

고객 정보를 한 번 입력하면 보험사 청구서가 채워지고, 고객이 폰 화면에서 동의·서명한 뒤 모바일팩스로 보내는 설계사용 앱입니다.

- 삼성화재 공식 청구서(2026.04 양식)에 그대로 기재, 그 외 보험사는 표준 양식
- 고객 서명: 청구 내용 확인 → 필수·선택 동의 직접 선택 → 손가락 서명 (서명 후 내용이 바뀌면 다시 서명)
- 팩스: 팩스용 PDF를 만들어 폰의 모바일팩스 앱으로 공유(팩스번호 자동 복사), 또는 PDF 저장 후 첨부
- 입력값·서명·첨부는 폰 화면 안에서만 처리되고 어디에도 저장·전송되지 않습니다 (보험사별 팩스번호만 폰에 저장)
- 오프라인에서도 열림 (PWA)

라이선스: 앱 코드 사용은 소유자 전용. `vendor/`의 pdf-lib, html2canvas는 MIT 라이선스 (`vendor/LICENSES.txt`).
